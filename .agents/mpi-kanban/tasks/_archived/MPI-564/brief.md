# MPI-564 - Gallery card notes indicator

Cards already carry a Favourite toggle and a Reuse-prompt button in the
top-right action column. Notes exist per history item (item.notes, edited from
the card context menu, persisted to the item sidecar) but nothing on the card
says a note is there.

Add a third icon between them - order top to bottom: Favourite, Notes, Reuse -
shown ONLY when the card's selected item has notes. Persistent (not
hover-revealed), like a favourited heart, so a shared project can be scanned for
annotated cards. Click opens the same notes editor the context menu opens.
